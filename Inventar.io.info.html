04 / TECNOLOGÍA Y CONFIANZA

Una base preparada para operar.

La arquitectura mantiene las reglas de stock y permisos en el backend y separa el dominio de la interfaz y la persistencia.

Stack y recorrido de una operación

.NET 10ASP.NET CoreEF CoreReact 19TypeScriptVite / PWASQLiteDocker
Cliente PWA→API→Aplicación→Dominio→Persistencia

Decisiones que importan

Dominio protegido

Stock, disponibilidad y reservas tienen invariantes de negocio explícitas.

Aislamiento por inventario

La sesión y el rol se verifican en backend para cada operación.

Consistencia

Transacciones y concurrencia optimista protegen cambios simultáneos.

Despliegue compacto

La API sirve la PWA; Docker Compose prepara el servicio para el servidor.
